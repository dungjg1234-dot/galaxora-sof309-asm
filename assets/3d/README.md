# Tài nguyên 3D khu vực khám phá vũ trụ

Dành cho Hệ Mặt Trời, thiên hà, tinh vân, hố đen (plan.md mục 9.8).
Mỗi hành tinh có thư mục riêng trong `solar-system/`. Các tệp `ban-goc.glb.gz` là gói nén không mất dữ liệu của GLB nguồn. Xem [danh sách gói tải](../../docs/3d-assets.md#gói-tải-tối-ưu).

- `textures/`: texture dùng chung cho các thiên thể
- `environments/`: nền/skybox/HDR
- `references/`: ảnh tham khảo (không đưa lên website)

Model của **sản phẩm cửa hàng** để ở `assets/3d-models/`, không để ở đây.
