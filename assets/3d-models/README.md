# Mô hình 3D sản phẩm

Đặt file mô hình 3D của **sản phẩm cửa hàng** vào đây (ưu tiên `.glb` / `.gltf`).

Theo plan.md (mục 5.3), mỗi model cần ghi metadata: tên file, sản phẩm liên kết,
định dạng, dung lượng, license, nguồn, tác giả/attribution, trạng thái duyệt.
Thông tin này sẽ được ghi trong `docs/3d-assets.md`.

Kiểm tra giấy phép (đặc biệt thương mại/ghi công) trước khi đưa model từ Sketchfab vào dự án.
